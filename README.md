# golden-private

Private landing zone for golden sessions: conversations with agents worth keeping. Captured with [`/golden`](https://github.com/smarchone/skills/tree/main/productivity/golden).

```
sessions/<YYYY-MM-DD>-<slug>/
  session.md     frontmatter (why, provenance, labels) + full text of every turn
```

Raw transcripts stay local; `source_path` points at them best-effort.
